# 1. Record architecture decisions

Date: 2026-11-08

## Status
Accepted

## Context
Decisions about this project (LLM choice, storage layout, hosting) should be traceable.

## Decision
Use Architecture Decision Records (Michael Nygard format) in `docs/adr/`, one file per decision, numbered sequentially.

## Consequences
Every non-trivial change in architecture adds an ADR. Superseded ADRs are marked, not deleted.
